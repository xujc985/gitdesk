# GitDesk 多平台安装与兼容说明

## 支持范围

| 平台 | 启动方式 | 应用入口/图标 | 验证情况 |
|------|----------|---------------|----------|
| Windows 10/11 | `run.bat`、`run.ps1`、`gitdesk.pyw` | `install-windows.ps1` 创建带 `.ico` 的桌面快捷方式 | 本机实测 |
| Linux | `sh run.sh` | `sh install-linux.sh` 安装用户级 `.desktop` | 脚本/静态兼容测试 |
| macOS | `sh run.sh` 或 `./run-macos.command` | PNG/SVG 窗口图标；可按需制作 `.app` | 脚本/静态兼容测试 |

**没有 Electron、WebView 或 Node.js 运行时。** 所有平台都使用 Python + Qt Widgets + 本机 Git。

## 通用依赖

- Python 3.10+（建议 3.11–3.14）。
- Git 已安装并可在 PATH 中找到。
- PySide6 Essentials：

```sh
python -m pip install -r requirements.txt
# Linux/macOS 也可能使用 python3
python3 -m pip install -r requirements.txt
```

首次运行 `run.bat` / `run.sh` 会自动检查并安装缺失的 Qt 依赖。企业网络可能需要配置 pip 镜像或代理。

## Windows

### 启动

双击 `run.bat`，或在 PowerShell 中：

```powershell
.\run.ps1 "E:\path\to\repo"
```

### 桌面图标

```powershell
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
```

脚本在当前用户桌面创建 `GitDesk.lnk`，使用 `assets/gitdesk.ico`，不会修改系统目录或其他用户配置。

`.ico` 含 16、24、32、48、64、128、256 像素多尺寸图标；高分屏窗口使用 SVG。

## Linux

```sh
sh run.sh /path/to/repo
```

安装应用菜单入口：

```sh
sh install-linux.sh
```

安装到 `${XDG_DATA_HOME:-~/.local/share}/applications/gitdesk.desktop`，不需要 root。若菜单不立即显示，注销重新登录或运行桌面环境的菜单刷新命令。

### 常见 Linux 依赖

不同发行版需要系统 Qt 运行库（XCB、OpenGL、字体等）。例如 Debian/Ubuntu 可能需要：

```sh
sudo apt install libxcb-cursor0 libgl1 libegl1 libxkbcommon-x11-0
```

中文显示推荐安装 `fonts-noto-cjk`；等宽字体使用 `DejaVu Sans Mono`。无显示服务器只能用于测试：

```sh
QT_QPA_PLATFORM=offscreen python3 -m unittest tests.test_qt
```

## macOS

```sh
sh run.sh /path/to/repo
# 或在终端中
./run-macos.command /path/to/repo
```

Qt 使用原生 Cocoa；UI 字体为苹方（PingFang SC），等宽字体为 Menlo。

当前未生成签名/公证的 `.app` 安装包，因此**不要把未经签名的应用移到其他 Mac 后当作已分发应用运行**。本地通过脚本启动不需要关闭 Gatekeeper。后续可用 `py2app` 打包并签名。

## 路径与 Git 兼容

- 仓库路径、文件名均通过参数列表传递，不拼接 shell 命令。
- 支持中文、空格、重命名路径，Git status 使用 NUL 分隔解析。
- 从仓库任意深度子目录打开，自动定位顶层仓库。
- 短暂 `index.lock` 竞争会有限重试；不会强制删除其他程序的锁文件。
- SSH key、Git Credential Manager、Windows 凭据管理器、macOS Keychain、Linux credential helper 均由本机 Git 处理。

## 资源与故障日志

- 图标母版：`assets/gitdesk.svg`
- 通用图标：`assets/gitdesk.png`
- Windows 多尺寸图标：`assets/gitdesk.ico`
- 用户设置：`~/.gitdesk/settings.json`
- 启动错误日志：`~/.gitdesk/startup-error.log`

Windows 无控制台启动失败会显示错误框；Linux/macOS 在终端输出错误。将对应日志附在问题反馈中即可定位。

## 测试

```sh
python -m unittest discover -s tests -v
# Linux/macOS 可替换为 python3
```

共 61 项测试，包含真实 Git 仓库、Qt 工作流、图标资源和多平台启动脚本检查。Linux/macOS 的窗口、安装菜单和系统凭据需要在对应系统上做最终人工确认；本机实测为 Windows。
